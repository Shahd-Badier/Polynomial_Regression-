# Polynomial Regression for MPG Prediction

## Project Overview
This project explores Polynomial Regression for predicting vehicle fuel efficiency (Miles Per Gallon - MPG) based on horsepower using the Auto MPG dataset.

## Dataset
The project uses the Auto MPG dataset, containing vehicle information and fuel efficiency measurements.

## Optimization Methods
Five optimization methods are implemented and studied:

1. Gradient Descent (GD)
2. Stochastic Gradient Descent (SGD)
3. Mini-Batch Gradient Descent
4. RMSprop
5. Adam

## Project Structure
- `Notebooks/`: Contains the five Jupyter notebooks.
- `Dataset/`: Contains the Auto MPG dataset used as a backup.

## Data Loading
The notebooks attempt to load the dataset from the UCI Machine Learning Repository first. A local backup dataset is used if the online source is unavailable.
